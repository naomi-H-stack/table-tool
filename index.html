On desktop, headers become clickable (click again to reverse). On phones it depends on your mobile layout (section 7): with stacked cards a small “Sort by…” menu appears above the table; with a scrollable table the headers stay tappable. Price and weight columns sort by number; text columns sort A–Z. Choose which columns are sortable in section 7.

7  Per-column & mobile

Below the breakpoint the table switches to your chosen mobile layout. Stacked cards (default) reflows each row into a labeled card. Scrollable table keeps the real table — so bottom-aligned headers and tappable sorting work on phones — and shows a “Swipe to compare →” cue so readers notice the off-screen columns. Show max rows (stacked cards only) shows just the first few products on phones and adds a tappable button to reveal the rest; set the button labels alongside it. Hide last N rows permanently drops your lowest-priority products on phones (no reveal button). Per column: set alignment, untick Show on mobile to hide it on phones, or untick Sortable to lock it from reader sorting.
